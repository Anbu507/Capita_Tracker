# Changelog

## 1.1.1 — made for the shopkeeper too

The shopkeeper only uses WhatsApp, YouTube and UPI, so everything new for them uses just those
habits: WhatsApp messages, big numbers, item pictures and a calculator-style number pad.

**For the shopkeeper**
- **Shop view** — a full-screen page to hand over at the counter: "Money left with you" in huge
  digits, 🥚 / 🍌 with big − / + buttons, a number pad for today's amount and one big Save.
  After saving: a big ✓, the new balance, "Send on WhatsApp", "Done" and "Made a mistake? Undo".
- **WhatsApp message after each entry** (optional tick box, remembered): date, items, amount and
  the money left with the shop. Edits are sent as a "✏️ Correction".
- **WhatsApp statement** (History → Send statement): everything since money was last given, with
  totals that add up like an account book.

**For me**
- Shopkeeper's WhatsApp number in Settings (+91 added to 10-digit numbers), with a test message.
- One-tap amount chips with my last few amounts in the entry sheet.
- Purchase rows use a bag icon instead of repeating the egg emoji.
- Version shown in Settings.

No server, no account, no new data format: old data and v1.0.0 backups load as they are.

## 1.0.0 — base version

The student's tracker: prepaid balance, daily purchase log, top-ups, history by month with
running balance, Insights charts (balance over time, spend per day/week), backup export/import,
light/dark themes, offline support, responsive phone/tablet/desktop layout.
